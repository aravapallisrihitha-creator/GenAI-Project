                                                     Abstract

The increasing adoption of Generative Artificial Intelligence in healthcare has created opportunities for providing accessible health information through conversational chatbots. However, AI-based systems may generate inaccurate, misleading, or potentially harmful medical information, which can pose risks to users. The proposed project, "Guardrails and Kill Switch for a Health Advisory Chatbot," aims to develop a safety-focused chatbot that provides general health information while incorporating mechanisms to identify and prevent unsafe AI-generated responses.

The system uses React with Vite for the user interface and FastAPI with Pydantic for backend processing and input validation. An AI model, implemented using Ollama or a hosted Large Language Model (LLM) API, generates health-related responses. MongoDB and Chroma are used to store and retrieve trusted health reference materials. Python-based guardrails examine user queries and AI-generated responses to identify potentially unsafe content. A dedicated Kill Switch mechanism is designed to interrupt response generation when predefined high-risk conditions are detected, preventing the chatbot from continuing with potentially harmful information. Additionally, logging and a golden question set are used to monitor safety-related events and evaluate system behaviour.

The primary objective of this project is to improve the safety, reliability, and responsible use of Generative AI in health advisory applications. The expected outcome is a chatbot that provides general health information with appropriate safety checks, restricts potentially harmful responses, and directs users towards professional medical assistance when necessary. The system is intended to support health information access and not replace professional medical diagnosis or treatment.
